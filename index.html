This Privacy Policy explains how FleetOps collects, uses, stores, and protects user information when using the application.

1. Legal Basis for Data Processing

The processing of users' personal data is carried out in accordance with the Republic of Indonesia Law Number 27 of 2022 concerning Personal Data Protection (UU PDP).

2. Information We Collect

The application may collect the following information:

  • User name
  • User email address
  • Vehicle data
  • Uploaded photos or documents
  • Device location (if location features are used)

3. Use of Information

The collected information is used to:

  • Process login and user authentication
  • Operate application features
  • Manage vehicle and operational data
  • Improve application performance and services

4. Application Permissions

The application may request the following permissions:

  • Camera — to capture vehicle or inspection photos
  • Location — for vehicle tracking or operational features
  • Storage — for file upload and storage

5. Data Storage and Retention

User data will be stored as long as the account remains active or as necessary to provide application services.

After the account is deleted or the user requests data deletion, the data will be permanently deleted within a maximum of 30 days, unless otherwise required by applicable laws.

6. User Rights

Users have the right to:

  • Access their personal data
  • Update their personal data
  • Request deletion of personal data
  • Withdraw consent for data usage

Requests related to personal data can be submitted through the available contact email.

7. Data Security

We strive to maintain the security of user data by implementing appropriate protection measures and do not share data with third parties without user consent, except as required by law.

FleetOps is not intended for children under the age of 13. We do not knowingly collect personal data from children.
